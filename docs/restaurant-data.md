# 식당 초기 데이터 정책 및 검증 체크리스트

정책 변경일: 2026-10-27. 사용자가 승인한 v2 식당 **20곳 전체**를 초기 등록 대상으로 사용한다. 상세 검증은 개발 완료 후 별도 진행하며, 등록 승인은 상세 정보 검증 완료를 뜻하지 않는다.

## 데이터 기준과 보존

- **활성 초기 데이터:** [data/restaurants.json](../data/restaurants.json)의 restaurants 배열 전체. 검증 상태나 sourceUrl 유무로 식당을 제외하지 않는다.
- **보존 원본:** [yonsei-eats-restaurants-v2.json](../data/yonsei-eats-restaurants-v2.json). 원본의 ID·이름·음식 종류·참고 링크를 승계했다. 원본은 수정하지 않았다.
- 정육면체는 제외하고 오천집 신촌점을 포함한다. 더도이축산직영점 신촌점도 유지한다.
- v3 검증 현황과 v4의 3곳 제한은 더 이상 초기 등록/게시 기준이 아니다. 현재 폴더에는 해당 파일이나 기존 로더가 발견되지 않았으며, 없는 파일을 수정/삭제했다고 주장하지 않는다.
- 원본의 후보/게시 보류 메모는 과거 이력으로만 보존한다. 충돌 시 이 문서와 활성 초기 데이터의 정책이 우선한다.
- 원본 주소 및 포괄적 verifiedAt에는 필드별 근거가 부족하여 활성 데이터에서는 주소와 검증 날짜를 모두 null로 두었다. 원본 값은 삭제하지 않았다. sourceUrl은 미검증 참고 링크다.
- 원본 isFranchise=true 두 건은 잠정 분류로 보존본에 남겼으며, 활성 데이터는 재확인 전 모두 null이다. 개인 식당 18곳이라는 검증을 새로 주장하지 않는다. 프랜차이즈 수·업종·지역 등 적합성도 후속 체크 대상이며 임의 교체하지 않는다.

## UI·검색·필터·지도 계약 (구현은 별도 단계)

| 항목 | 적용 규칙 |
|---|---|
| 기본 카드·상세 | 검증 상태와 무관하게 20곳 모두 조회 가능. 이름·승인된 음식 종류 표시 |
| 검색 | 이름은 20곳 모두 대상. 메뉴는 확인된 값만 검색하며 null 메뉴로 이름 검색 결과를 제거하지 않음 |
| 종류 필터 | 승인 데이터 category 사용. 복합 표기(예: 한식·국밥)의 분류 정규화는 구현 단계에서 결정 |
| 가격 필터 | representativePrice=null이면 '정보 확인 중' 또는 가격 생략. 기본 목록에는 포함, 숫자 가격 범위 선택 시 미확인 가격을 범위 일치로 간주하지 않음 |
| 평점 | 자체 리뷰 없으면 '아직 리뷰 없음'. 외부 평점/0점 대체 금지. 평점 범위 선택 시 리뷰 없는 식당을 숫자 평점 일치로 간주하지 않음 |
| 주소·메뉴·시간·사진 | null은 '정보 확인 중' 또는 항목 숨김. 가짜 주소·메뉴·가격·사진 URL 생성 금지 |
| 영업 상태 | operatingStatus=null은 '영업 상태 확인 중' 또는 숨김. 영업시간만으로 현재 '영업 중' 단정 금지 |
| 지도 | latitude/longitude 둘 다 확인된 유효 숫자일 때만 마커 생성. 하나라도 없으면 마커 없음·'위치 확인 중'. 목록/상세는 유지 |
| 길찾기 | 좌표 필요한 길찾기는 미확인 상태에서 생성하지 않음 |

이번 변경은 JSON과 문서만 정리한다. 카드·검색·필터·상세·지도 컴포넌트, DB seed 및 외부 API는 이번에 구현/실행하지 않는다.

## 검증 기록 방법

- 상태: pending(미확인), partial(일부 확인), verified(필드별 증거 확인 완료). 등록 대상 여부와 분리한다.
- 실제 확인한 항목만 체크한다. 미확인 값은 null 유지. 확인된 값을 기록할 때 출처 URL과 실제 확인 날짜를 아래 식당 항목에 함께 기록한다.
- 날짜는 YYYY-MM-DD(Asia/Seoul). 정책 변경일·원본 작성일·검색일을 영업 검증 날짜로 사용하지 않는다.
- JSON verificationStatus를 진행도에 맞춰 갱신하고 verifiedAt은 상세 검증 완료 때만 채운다. 부분 확인 날짜는 아래 필드별 기록에 남긴다.
- 현재 모든 체크박스는 미완료이며 외부 링크를 새로 방문하거나 영업/주소를 검증하지 않았다.
